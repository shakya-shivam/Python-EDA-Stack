# Python-EDA-Stack 📊

A comprehensive, step-by-step guide and modular cheat sheet for Exploratory Data Analysis (EDA) in Python. This repository contains structured Jupyter Notebooks covering everything from basic array manipulations to advanced statistical visualizations.

## 🚀 Tech Stack
- **NumPy**: Numerical computing, mathematical operations, and array manipulation.
- **Pandas**: Data manipulation, aggregation, and time-series analysis.
- **Matplotlib**: Core data visualization and object-oriented plotting.
- **Seaborn**: Statistical data visualization, matrix plots, and advanced styling.

## 📂 Repository Structure

### 1. NumPy
- Array creation, dimensions, indexing, and slicing.
- Mathematical operations and the concept of broadcasting.

### 2. Pandas
- Data filtering, cleaning, and basic transformations.
- **Split-Apply-Combine**: Advanced GroupBy, multiple aggregations, and Pivot Tables.
- **Data Integration**: SQL-style Joins (Inner, Left, Right, Outer) and Concatenation.
- **Time Series**: Datetime indexing, resampling, and handling messy date formats.
- **Advanced Tricks**: Custom row/column operations using `apply()` and `map()` with lambda functions.

### 3. Matplotlib
- Basic line plots, scatter plots, and working with subplots.
- **Object-Oriented Interface**: Deep dive into Figure and Axes objects for granular control.
- Customizing canvas size, aspect ratio, and DPI.

### 4. Seaborn
- **Categorical Plots**: Bar, Count, Box, Violin, Strip, and Swarm plots.
- **Distribution Plots**: Histograms, KDE (Kernel Density Estimate), and Rug plots.
- **Regression & Matrix Plots**: Trend analysis using `lmplot()`/`regplot()`, and visualizing relationships using Correlation Heatmaps and Clustermaps.
- Customizing global styles, themes, and color palettes.

## 💡 Signature Features
- **Pro-Tips**: Every notebook includes real-world `# 💡 Pro-Tip` comments highlighting edge cases, performance optimizations, and industry best practices.
- **Action-Oriented Comments**: Code blocks are documented using a consistent `# Here, I am...` signature style for absolute clarity.
